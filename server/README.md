# راهنمای استقرار بکاند و تنظیمات تپسل پلاس (پروژه: رقابت کن، جایزه ببر)

این مستندات شامل راهنمای راه‌اندازی سرور بکاند، پایگاه داده و تنظیمات رسمی تپسل پلاس است.

## ۱. نحوه دریافت و تنظیم کلیدهای تپسل پلاس (Tapsell Plus)
۱. به پنل توسعه‌دهندگان تپسل در [tapsell.ir](https://tapsell.ir) مراجعه و ثبت‌نام کنید.
۲. یک اپلیکیشن جدید از نوع اندروید ثبت کنید.
۳. مقدار **Tapsell App Key** را کپی کنید.
۴. یک جایگاه تبلیغاتی از نوع **ویدیویی جایزه‌دار (Rewarded Video)** بسازید و **Zone ID** آن را کپی کنید.
۵. این مقادیر را می‌توانید در:
   - فایل `.env` اندروید یا پنل مدیریت برنامه
   - یا در متغیرهای محیطی سرور بکاند قرار دهید.

## ۲. متغیرهای محیطی سرور (.env)
```env
PORT=3000
ADMIN_KEY=ReqabatAdmin2026
TAPSELL_APP_KEY=your_tapsell_app_key_here
TAPSELL_ZONE_ID=your_tapsell_rewarded_zone_id_here
```

## ۳. اجرای سرور بکاند
با دستورات زیر می‌توانید سرور را اجرا کنید:
```bash
cd server
npm install
npm start
```
سرور بر روی پورت ۳۰۰۰ اجرا می‌شود و پنل مدیریت تحت وب در آدرس `http://localhost:3000` در دسترس خواهد بود.

## ۴. چرخه ۲۴ ساعته و قوانین ضد تقلب
- دوره ۲۴ ساعته به صورت مستقل برای هر کاربر با `startTime` و `endTime` سروری مدیریت می‌شود.
- پس از اتمام ۲۴ ساعت، ۵۰ مربع به صورت خودکار بازنشانی می‌شوند ولی امتیازات پیشین کاربر دست‌نخورده باقی می‌ماند.
- هر مربع در هر دوره تنها ۱ بار مجاز به دریافت ۱ امتیاز است و درخواست‌های تکراری با کد خطای ۴۰۹ رد می‌شوند.
