ارسال اعلان پوش همگانی (Push Notification)

ارسال پیام فوری به دستگاه کاربران از طریق سرویس ابری OneSignal. این پیام مستقیماً در نوار اعلان گوشی کاربران نمایش داده می‌شود.

وضعیت سرویس OneSignal
در حال بررسی...
کلیدهای ارتباطی OneSignal به دلایل امنیتی در متغیرهای محیطی Render سرور نگهداری می‌شوند و هرگز در مرورگر کاربر فاش نمی‌شوند.
برای ارسال اعلان به کاربران واقعی، شناسه ONESIGNAL_APP_ID و ONESIGNAL_REST_API_KEY در پنل مدیریت متغیرهای محیطی سرویس Render قرار داده می‌شوند.

احراز هویت مدیریت (ADMIN_KEY)

برای امنیت پنل و جلوگیری از دسترسی غیرمجاز به اطلاعات کاربران، کلید امنیتی مدیریت در مرورگر شما ذخیره شده و با هر درخواست به سرور ارسال می‌شود.

مشخصات فنی سرور و پایگاه داده

  • میزبانی سرور: Render Cloud Service (Node.js)
  • پایگاه داده: Supabase Cloud PostgreSQL (Connection Pooler)
  • اعلان‌های پوش: OneSignal REST API v1
  • سیستم امنیت تبلیغات: توکن‌های یکبارمصرف و اعتبارسنجی تپسل پلاس
